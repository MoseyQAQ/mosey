## 关系图

- 图1为下游，按博士学生、博士后等真实关系分组；图2为上游与同门。
- 延续参考图的 `#F6F4EF` 米白背景、`#24333D` 深色文字、蓝/绿/紫辅助色。使用支持中文的清晰字体。
- 人物卡片优先呈现姓名、关系/时间、当前或生前任职；必要时加一项代表贡献或荣誉。
- 指导箭头从导师指向学生；同门通过共同导师表达，合作和访问不得画成博士指导关系。
- 主体人物突出，布局按人数调整。优先减少次要节点，不无限缩小字体；避免线条穿过文字。
- 用 SVG 等确定性矢量方式排版，导出 PNG，保留可编辑文件。关系图无需生成式人像或装饰。
- 生成后逐张查看完整图和文字细节，检查箭头、溢出、中文字体、关系与笔记的一致性。
- 不强制复制参考图中的日期、路径、脚本信息等页脚；对外图片只保留读者需要的内容。

## 独立人物封面

封面不是关系图。采用竖版，约 2:3 或现有样本比例，信息层级为：
1. 人物真实照片与姓名；
2. 一句话学术定位、简洁现职；
3. 大字号总被引与 H-index；
4. 3–5 项核实后的代表贡献，必要时配科学示意图。

配色可借鉴深蓝金或浅蓝紫两种样本，人物特点和可读性优先。封面不写数据库来源与日期；也不添加未经证实的引语、奖项、机构标志或“首创”结论。

### 真实照片与内置生图流程

- 从本人或机构主页等可靠来源获取照片并核实身份，保存到选题的 `sources/`，在 `note.md` 留下出处。不要把旧生成封面中的人像直接当作可核实原照。
- 可使用内置 `image_gen` 制作封面。先按当前 imagegen 技能与工具说明读取本地照片、样式参考，再作为具名输入提供给工具。
- 明确真实照片是身份与肖像素材，旧封面仅是版式参考；要求保留原照人物身份和外貌，不凭姓名生成替代照片，不美化到改变年龄或五官。
- 生成式编辑不能保证像素级保留。生成后与原照对照，检查明显面容漂移；不能忠实保留时不要交付为真实肖像封面，应保留原照并说明需要改用原照直接排版。
- 提供准确、逐字的标题、指标、职位和贡献短句。示意图只用于解释概念，不能伪装成论文结果曲线。
- 生成后检查每一个数字、姓名、中文、公式与科学示意，错误须修正；不能因为整体美观就忽略文字错误。
- 最终图复制或保存为选题目录的 `cover.png`，不能只留在工具默认输出目录。保留实际提示词便于后续复现。
- 找不到可信肖像时，报告缺项并继续完成笔记、关系图与正文；不虚构一张“照片”。工具不可用时说明封面未完成，不默默改用需要 API key 的方式。

### 封面提示词模板

```text
任务：制作一张用于学术族谱的小红书竖版人物封面。
输入1：{真实肖像文件}。这是目标人物真实照片，保持身份、年龄、五官与自然外貌。
输入2：{Vanderbilt 或 Rabe 样式参考}。只参考版式和色彩，不复制其人像、文字或指标。
布局：上部姓名、真实肖像与简洁身份；中部醒目的两项指标；下部代表贡献卡片。
整体：严谨、清晰、有层次，借鉴参考图，适合手机阅读。
必须逐字使用以下文字：
{姓名}
{一句话学术定位}
{机构与职位}
总被引：{数值}
H-index：{数值}
代表贡献：
{贡献1}
{贡献2}
{贡献3}
{可选贡献4–5}
限制：不写数据来源和日期；不添加引语或未经核实的荣誉；
不生成替代人物；不伪造科学数据；确保中文与数字准确。
```
