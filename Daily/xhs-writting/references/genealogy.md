# 学术族谱：调研、制图、写作

流程固定为：**调研并保存 note.md → 制作两张关系图与独立人物封面 → 写 xhs.md**。原始资料可充分，公开稿精简；制图与正文始终取自同一份核实过的笔记。

## 1. 调研与 note.md 模板

先核实人物身份，再查本人主页、机构页面、CV、学位论文/学位记录、组内 alumni 页面等直接证据。职位用现行机构记录核实，历史 CV 仅证明对应时期的经历。指标按主 skill 的数据库规则读取。

按以下结构填写 `note.md`：

```markdown
# {人物姓名}｜学术族谱研究笔记

## 1. 人物概况
当前机构、职位、研究领域、主要经历、重要荣誉。
事实后附来源；已故人物区分生前职位与当前状态。

## 2. 学术指标
数据库、档案 URL/标识、实际查询日期。
总被引、H-index；单篇被引使用的记录和计数口径。
保存必要来源快照，不将缺失值写为零。

## 3. 研究主线
按科学问题或发展阶段分组，说明各组工作的联系。
将自己的综合归纳与作者明确提出的观点区分。

## 4. 代表工作
题目｜作者｜期刊与年份｜DOI｜核心贡献｜被引次数｜来源。
调研覆盖主要方向；选出三篇最适合推文的作品并说明理由。

## 5. 上游与同门
姓名｜关系类型｜机构与时期｜当前/生前职位｜直接证据。
包括博士导师、已核实的博后导师、主要同门；
必要时延伸到导师的导师。

## 6. 下游培养关系
姓名｜博士/博后/共同指导等｜时期｜当前/生前职位｜直接证据。

## 7. 图文选材
进入图1、图2、封面和推文的人物及贡献。
真实肖像的来源页面与文件；封面准确文案。

## 8. 未核实与交接
存在分歧或缺证据的关系、未取到的指标、标题/配图状态。
```

### 关系与选材规则

- 师生、博后、访问、合作等关系逐项核实并标明；共同署名不证明指导关系。
- “博士同门”指共享博士导师，不代表同一时期在组。共同指导需保留其他导师，不能画成独占关系。
- 调研不以穷尽全体成员为目标。关键导师与主干关系优先，其余优先领域 big name、中国学者及与研究主线紧密相关的人物。
- big name 用代表贡献、重要奖项或领域影响来判断，不仅凭机构名气。中国背景不从姓名推断；不清楚时只写核实的姓名与任职。
- 图中可比推文容纳更多人物；不要为了增加节点纳入未核实关系。
- 三篇代表作兼顾研究主线和影响力，避免仅按被引排序或都取同一系列。合作论文客观表述贡献。

## 2. 画图与封面

按 [genealogy-visuals.md](genealogy-visuals.md) 制作：
1. `fig1.svg` / `fig1.png`：博士学生、博士后等下游关系。
2. `fig2.svg` / `fig2.png`：上游导师与主要同门。
3. `cover.png`：真实肖像、姓名、身份、总被引、H-index、代表贡献。

保存制图脚本或其他可编辑源文件。检查人物关系、标签、箭头方向、文字可读性与数字一致性后再压缩正文。

## 3. 固定推文模板

使用下面的栏目名称与顺序；将花括号替换为事实，不把模板提示保留在稿中。没有核实的可选经历可以省略，不补造内容。保持全文不足 1000 字符。

```text
学术族谱｜{姓名}

👤 人物简介
{姓名}，现任{机构、职位}，主要研究{领域}。
{最重要的一项身份或荣誉，如有}。
总被引{数值}，H-index {数值}。

🔬 研究主线
{用一段话串起主要问题、方法及方向演变。}

📚 三篇代表作
① {期刊、年份}：{贡献短句}。被引{次数}。
② {期刊、年份}：{贡献短句}。被引{次数}。
③ {期刊、年份}：{贡献短句}。被引{次数}。

👥 图1｜学生与博士后
{主要博士学生：姓名、现职。}
{主要博后：姓名、现职；共同指导须注明。}

🌳 图2｜导师与同门
{博士导师及必要的上一代师承。}
{主要同门；博后导师在有证据时补充。}

#学术族谱 #{研究领域}
```

公开稿和封面均不写指标来源或日期，来源与实际日期完整留在 `note.md`。不在结尾强行加一句没有信息量的赞语。英文长职位可用准确的简写或中文表达，把篇幅留给贡献与重要关系。

## 4. 交付检查

- 笔记事实有出处，关系分类可靠，人物身份未混淆。
- 两张图均可编辑，PNG 已逐张查看；封面使用核实身份的照片。
- cover、fig1、fig2 与 xhs.md 使用同一组指标、职位和关系。
- 公开内容没有数据库名称或查询日期；实际查证日期仍在 note.md。
- 完成文字计数，交付顺序 cover → fig1 → fig2。
